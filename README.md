# Portfolio – Timéo Ruiz

Portfolio en HTML, CSS et JavaScript, sans framework ni bibliothèque.

## Fichiers
- `index.html` : structure et contenu
- `style.css` : apparence (thème clair/sombre, mobile)
- `script.js` : comportements (filtres, mixer, forme d'onde, etc.)
- `cv.pdf` : CV téléchargeable

## Mise en ligne avec GitHub Pages
1. Crée un dépôt public (par exemple `portfolio`).
2. Envoie-y tous les fichiers de ce dossier.
3. Dans **Settings → Pages**, choisis la branche `main` et le dossier `/ (root)`.
4. Le site sera disponible à `https://TON-PSEUDO.github.io/portfolio/`.
